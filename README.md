# Snowline Heights — room catalogue website

Static, mobile-first room catalogue for Vercel. The website uses `index.html` and the supplied `assets/` folder (real room photographs and room-tour videos).

## Deploy
Upload the contents of this folder to the root of the connected GitHub repository `avinavrathore7-spec/snowline-heights-website` (not the parent folder). Keep the `assets` folder alongside `index.html`. Vercel will automatically deploy the new commit.

Rates shown are per room per night for 2 adults: 1st floor ₹1,500; 2nd floor ₹2,000; 3rd floor ₹2,500; Top floor ₹3,000.
